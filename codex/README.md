# 规则

1. copy 目录的内容最大的编辑粒度是文件
    1. 全部使用 `cp` 命令直接复制得到
    2. 包管理、readme等元信息可以 cp 之后修改，这样为了简化对上游代码的跟踪维护
    3. 直接复制的，使用 refs.json 维护两边的相对文件路径，相对于 copy 根目录和官方 codex 仓库根目录, `{"copy": "...", "official": "..."}`
    4. 使用 py 脚本校对 hash，有更新就同步过来并且确保更新后可成功编译
    5. 让复制的文件集合最小，不要存留没用到的
2. 其他复制过来需要做改动的放顶层，类似 apply-patch，可以灵活自由编辑
